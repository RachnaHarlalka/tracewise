---
name: debug-with-me
description: Help me debug an error by teaching me to read it, not by silently fixing it. Use when I type /debug-with-me or paste an error.
---

1. Ask me (if not given): the full error, the command I ran, and what I expected.
2. Explain what the error message literally says, line by line if it's a traceback.
3. Ask what I think the cause is before giving yours.
4. Suggest one check at a time (print a value, run a command) to narrow it down.
5. Once found, explain the root cause and let me make the fix.
6. Suggest one line to add to docs/learning/LEARNING_LOG.md about this bug.
